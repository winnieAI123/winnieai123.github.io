## 为什么做这个

生鲜零售是贴身肉搏的价格战，价格和货盘几乎天天在变。七鲜的业务团队想判断对手盒马的打法——在动哪些品、怎么调价、是上新还是清仓——但靠人工去 App 一个个翻，既慢又难成体系，更看不出"这周比上周到底变了什么"。我想把这件事自动化成一句话：**每周自动采、自动比、一屏看。**

## 怎么做的

**跨周对齐是关键。** 每周把盒马单店全品类约 3000+ 个 SKU 拉一遍之后，真正难的是"如何确认这周的某个价格和上周是同一件商品"。我用商品 ID 做跨周主键匹配，并实测验证了它的稳定性——两周共有的商品里 99.4% 同款名称完全一致，证明同一商品不会被重新分配 ID。价格对比因此站得住，而不是拿会变的促销名硬配出一堆假涨跌。

**把噪声和真信号分开。** 采集走的是各分类的推荐流，每次抽样都有波动，会让"这次没采到"看起来像"被下架"。我把这类采样噪声和真实的上下架区分标注，避免给业务误报成"盒马砍了 X 个 SKU"。

**看板为业务扫读而设计。** 左侧冻结商品图片、名称、分类，右侧并排各周价格、环比涨跌（涨红跌绿）和状态徽章；顶部可按分类与状态（涨价 / 降价 / 上新 / 下架 / 缺货）筛选。几秒就能定位"盒马这周降价最狠的品"或"新铺了哪些 SKU"，把一次竞品复盘从半天翻页变成一屏扫读。
