## 做到了什么

搜"python"，拿回 30 条岗位的职位名称、薪资范围、经验/学历要求、技能标签、公司名称/行业/规模、招聘者信息、福利列表、工作地点。直接在 Excel 里按薪资排序、按区域筛选，几分钟看清整个市场。换个关键词，又是一份新的调研表。

## 为什么有用

求职市场调研、竞品公司人才需求分析、薪资 benchmark——都需要岗位数据来辅助决策。以前靠人肉翻 BOSS 直聘记录，现在换个关键词就是一轮新调研，当场出表。

## 技术深度

BOSS 直聘有三层反爬，每一层都需要独立突破：

**第一层：CDP 自动化检测。** 前端 JS 异步检测 Chrome DevTools Protocol 指纹（不只是 `navigator.webdriver`，还检测 `window.chrome` 完整性、`console.debug` getter 陷阱等），检测到后主动跳转 `about:blank` 清空 DOM。用 headless Chrome 秒被检测，即使用 stealth 脚本隐藏 `webdriver` 也没用。解决方案：headful Chrome + 独立 profile + 9222 调试端口，让浏览器 JS 自己算 token。

**第二层：`__zp_stoken__` 令牌。** 搜索接口需要有效令牌，令牌由一段 320KB 控制流平坦化混淆的 JS（`security-70043aea.js`）生成。完整逆向了状态机结构：`Cbl/Rbl/Mbl` 三级分发（取 `p` 的低 5/中 5/高 5 位），`z(seed, adjustedTs)` 遍历 navigator/screen/canvas/WebGL/CSS computedStyle 等 15+ 个环境维度采集指纹，编码成 token。通过 CDP 从浏览器导出含有效令牌的 cookie，再用纯 HTTP 发请求。

**第三层：频率风控。** 连续翻页过快触发 code=37（page 9+ 直接拦截），账户级异常触发 code=36。通过请求间隔 ≥3 秒 + 自动令牌刷新规避。

这套方案封装成了可复用的 Skill（`boss-search`），三个平台（Claude / ZCode / Codex）都能用，输入关键词直接出结果。
